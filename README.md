# Neo-Finder

Finderの操作に慣れた人が、2つの場所を見ながらファイルを整理するための、独立したmacOSアプリです。常時2ペイン、左右別のタブ、作業セット、グループ別のお気に入りを実装しています。

**バージョン0.1・自分のMacで使う初期実装**です。対象はmacOS 26以降のApple Silicon。Finderと併用します。実ファイルのコピー・移動・名前変更・ゴミ箱操作ができます。

## 起動と最初の設定

1. [dist/Neo-Finder.app](dist/Neo-Finder.app)を開きます。未作成の場合は下の手順でビルドします。
2. 「フォルダを登録…」で作業するフォルダを選びます。
3. 編集する場所では「クラウド同期されていないローカルフォルダとして編集を有効にする」にチェックします。初めて登録する場所は、チェックなしなら閲覧用です。
4. もう一方のペインをクリックし、コピー先のフォルダを同じように登録します。

編集対象は、本人が登録したクラウド同期対象外のローカルAPFSフォルダです。iCloud Drive・OneDrive等の場所への書込み、ネットワーク上の場所、別ボリュームへの移動は初期版の対象外です。既に編集を有効にした場所は、チェックなしで再登録してもその設定を引き継ぎます。

左右の状態は自動保存します。上部の「保存…」で、タブ・表示方法・分割比率を名前付きの作業セットにもできます。「お気に入り＋」では、場所へのリンクを用途別のグループに追加できます。

## 基本操作

| 操作 | 動作 |
|---|---|
| ダブルクリック / ⌘O / ⌘↓ | フォルダを開く、ファイルを既定アプリで開く |
| Return | 選択した1項目の名前を変更 |
| Space / ⌘Y | Quick Look |
| ⌘↑ / ⌘[ / ⌘] | 親へ移動 / 戻る / 進む |
| ⌘C → ⌘V | 現在のペインにコピー |
| ⌘C → ⌥⌘V | 現在のペインに移動（同一ボリューム） |
| 「右へコピー」「左へコピー」 | 選択項目を反対側の現在の場所へコピー |
| ⌘Delete / ⌘Z | ゴミ箱へ移動 / 取消可能な操作を戻す |
| ⇧⌘N / ⇧⌘G | 新規フォルダ / パスを指定して移動 |
| ⌘T / ⌘W | アクティブな側のタブを追加 / 閉じる。最後のタブならウインドウを閉じる |
| ⌘2 / ⌘3 / ⇧⌘. | リスト / 簡易カラム / 隠し項目の切替 |

各ペインの絞り込み欄は、現在のフォルダにある名前を対象にします。サブフォルダを検索する機能ではありません。リスト内の通常の文字入力は名前による選択です。

カラム表示は現在の場所と最大2階層の親を並べる簡易版です。フォルダ選択で階層を進めます。「表示」メニューで左右分割と上下分割を切り替えられます。

同名項目があれば「両方残す／スキップ／中止」を選び、上書きはしません。下部の「中止」は処理中の項目が終わってから止まります。完了済みの処理を自動で元に戻す操作ではありません。「履歴」から完了・部分成功・失敗を確認できます。

取消は今回の起動中に限ります。対象やその配下に外部変更がある場合、元の場所が埋まっている場合、ゴミ箱へのアクセス権がない場合などは保留します。

## ビルドと開発用テスト

Swift 6コンパイラを含むXcode Command Line Toolsが必要です。SwiftPMパッケージの言語モードはSwift 5、macOSの最低バージョンは26です。

```sh
./scripts/build.sh
open dist/Neo-Finder.app
```

引数なしはreleaseビルドです。デバッグ用は`./scripts/build.sh debug`、自動テストは`./scripts/test.sh`を実行します。

実ゴミ箱を使う1件は既定ではスキップします。専用の一時ファイルを移動・復元して確認する場合は`NEOFINDER_REAL_TRASH_TEST=1 ./scripts/test.sh`を使います。残りのテストは独立した一時領域で実行します。

ビルドスクリプトはApp Sandboxを有効にしたアプリを作り、ローカル用のad hoc署名を付けます。Appleによる公証や一般配布用の署名は行いません。アプリの権限確認は`.app`で行ってください。SwiftPMの実行ファイルを直接起動した結果は、同じ権限条件にはなりません。
