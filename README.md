# Neo-Finder

Finderの操作に慣れた人が、2つの場所を見ながらファイルを整理するための、独立したmacOSアプリです。常時2ペイン、左右別のタブ、作業セット、グループ別のお気に入りに加え、キーボードだけで「これをあそこへ」を完結させる機能を備えます。

**バージョン0.2・自分のMacで使う実装**です。対象はmacOS 26以降のApple Silicon。Finderと併用します。

> **0.2の変更は、macOS上でのビルド・自動テスト・実機確認がまだです。** 開発環境にSwiftコンパイラが無く、構文検査のみ行いました。最初に`./scripts/build.sh`と`./scripts/test.sh`を実行し、重要でないファイルで動作を確かめてから使ってください。詳細は[実装・検証状況](docs/implementation-status.md)にあります。

## 0.1からの主な変更

- **フォルダの登録が不要**になりました。App Sandboxをやめ、読める範囲はmacOSのプライバシー設定に従います。
- ローカルの場所はそのまま編集できます。クラウド同期・ネットワーク上の場所は、Neo-Finderメニューで許可した場合のみ編集します。
- 同名項目の**置き換え**（旧項目はゴミ箱へ退避）と、**別ボリュームへの移動**（コピー→検証→元をゴミ箱）ができます。どちらも⌘Zで戻せます。
- 名前変更・新規フォルダ・パス移動のダイアログを廃止し、その場で入力する方式にしました。
- 実行中に次の操作を出すと、順番待ちに入ります。

## 起動と最初の設定

1. 下の手順で`Neo-Finder.app`をビルドして起動します。
2. 「システム設定 › プライバシーとセキュリティ › フルディスクアクセス」でNeo-Finderを許可し、アプリを再起動します。許可しない場合は、デスクトップ・書類・ダウンロード等を初めて開くときにmacOSが個別に確認します。
3. 0.1の作業セットとお気に入りは、初回起動時にSandboxの保存場所から引き継ぎます（macOSが他アプリのデータへのアクセス確認を出すことがあります）。

ローカル用のad hoc署名のため、**ビルドし直すとフルディスクアクセス等の許可をやり直す必要がある**場合があります。

## キーボード操作

| 操作 | 動作 |
|---|---|
| ⌘K | パレット。フォルダ名の一部で移動、コマンド実行、作業セットの切替 |
| ⇧⌘G | パレットにパスを入力して移動。Tabで候補フォルダの中へ進む |
| ⇧⌘M / ⇧⌘K | 行き先のフォルダ名を入力して、選択項目を移動 / コピー |
| Tab | 反対側のペインへ |
| F5 / F6（⌘Return / ⇧⌘Return） | 選択項目を反対側へコピー / 移動 |
| Return | その場で名前を変更。Returnで確定、Escで中止、Tabで確定して次の項目へ |
| ⇧⌘N | 新規フォルダを作り、そのまま名前を入力 |
| Space / ⌘Y | Quick Look |
| ダブルクリック / ⌘O / ⌘↓ | フォルダを開く、ファイルを既定アプリで開く |
| ⌘↑ / ⌘[ / ⌘] | 親へ移動 / 戻る / 進む |
| ⌘T / ⌘W / ⇧⌘] / ⇧⌘[ | タブを追加 / 閉じる / 次 / 前 |
| ⌘C → ⌘V / ⌥⌘V | 現在のペインにコピー / 移動 |
| ⌥⌘C | 選択項目（無ければ現在の場所）のパスをコピー |
| ⌘Delete / ⌘Z | ゴミ箱へ移動 / 取消可能な操作を戻す |
| ⌘F / ⇧⌘F | このフォルダを絞り込む / サブフォルダまで展開して一覧にする |
| ⇧⌘T | 仕分けモード |
| ⇧⌘D | 左右を比較 |
| ⌘B / ⌥⌘B / ⇧⌘B | 収集棚に追加 / 棚の項目をここへ移動 / ここへコピー |
| ⇧⌘O | Finderの最前面ウインドウの場所と選択を取り込む |
| ⌘2 / ⌘3 / ⇧⌘. | リスト / 簡易カラム / 隠し項目の切替 |

F5・F6は、キーボード設定によってはfnキーと一緒に押します。⌘Return・⇧⌘Returnは同じ動作です。

## 新しい機能の使い方

**パレットと行き先指定。** 候補はお気に入り、最近使った場所（使用頻度と新しさで順位付け）、開いているタブ、左右のサブフォルダです。行き先指定（⇧⌘M）では反対側のペインが先頭に出ます。`/`や`~`から打つとパス入力になります。

**仕分けモード（⇧⌘T）。** 反対側のペインが大きなプレビューになります。1〜9で登録した行き先へ移動して次の項目へ進み、Spaceで飛ばし、Returnで名前を変えます。行き先は⌥1〜9、または未設定の番号を押して選びます。Escで終了します。

**日付連動タブ。** 「作業セット › このタブを日付連動にする…」で、`~/経理/{年度}年度/{MM}月`のようなパスを登録します。作業セットを開いたときと起動時に、その日のフォルダを開きます。無ければ作成を確認します。変数は`{yyyy}` `{yy}` `{MM}` `{M}` `{dd}` `{d}` `{年度}` `{令和}` `{令和年度}`、年度は4月始まりです。`{MM-1}`のように書くと、その月数だけずらした日付で計算します。

**左右を比較（⇧⌘D）。** 名前・サイズ・変更日で突き合わせ、＋（反対側に無い）、新、旧、≠（日時は同じでサイズか種類が違う）を名前の横に出します。「表示 › 差分を選択」で、反対側に無い項目と新しい項目をまとめて選べます。ファイルの中身は比べません。フォルダは名前の一致だけを見ます。両側を⇧⌘Fで展開すれば、サブフォルダを含めて比べられます。

**収集棚。** ⌘Bで複数のフォルダから項目を集め、行き先で⌥⌘B（移動）か⇧⌘B（コピー）を押します。棚はサイドバーの下に表示します。

## 編集の安全策

- 同名項目があれば「両方残す／置き換える／スキップ／中止」を選びます。「置き換える」は旧項目をゴミ箱へ移してから入れ替えます。フォルダは結合せず、丸ごと入れ替えます。
- 別ボリュームへの移動は、コピーして内容を照合したあと、元をゴミ箱へ移します。
- ボリュームの最上位、`/System`等、ホームフォルダとその標準フォルダ（デスクトップ、書類など）自体は、移動・名前変更・削除しません。
- クラウド同期・ネットワーク上の場所は初期状態では閲覧のみです。許可は「Neo-Finder › クラウド・ネットワーク上の編集を許可（実験的）」で切り替えます。OneDrive等での挙動は未確認です。
- 取消は今回の起動中に限ります。対象に外部変更がある場合、元の場所が埋まっている場合などは保留します。
- 下部の「中止」は、処理中の項目が終わってから止まり、待機中の操作も取り消します。「履歴」から完了・部分成功・失敗を確認できます。

## ビルドと開発用テスト

Swift 6コンパイラを含むXcode Command Line Toolsが必要です。SwiftPMパッケージの言語モードはSwift 5、macOSの最低バージョンは26です。

```sh
./scripts/build.sh
open dist/Neo-Finder.app
```

引数なしはreleaseビルドです。デバッグ用は`./scripts/build.sh debug`、自動テストは`./scripts/test.sh`を実行します。

実ゴミ箱を使う1件は既定ではスキップします。専用の一時ファイルを移動・復元して確認する場合は`NEOFINDER_REAL_TRASH_TEST=1 ./scripts/test.sh`を使います。残りのテストは独立した一時領域で実行します。

ビルドスクリプトはApp Sandboxを使わないアプリを作り、ローカル用のad hoc署名を付けます。Appleによる公証や一般配布用の署名は行いません。プライバシー設定の確認は`.app`で行ってください。
